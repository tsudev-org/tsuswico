8. Toàn vẹn file hệ thống & driver

Dùng 2 công cụ CHÍNH THỨC của Windows: DISM CheckHealth kiểm tra nhanh kho thành phần hệ thống, và System File Checker xác minh từng file hệ thống/driver so với bản gốc.

Công cụ kiểm traKết quảThời gian chạy
DISM CheckHealthCÓ THỂ SỬA ĐƯỢC - phát hiện lỗi component store, nên chạy DISM /RestoreHealthNhanh (<5 giây)
Về phương pháp và giới hạn

Nếu kết quả báo lỗi, chạy với quyền Administrator: DISM /Online /Cleanup-Image /RestoreHealth rồi sfc /scannow. Mục System File Checker mặc định TẮT (mất 5-15 phút) - bật bằng tham số --sfc.

9. Phát hiện mã độc - Windows Defender

0 mối đe dọa

Đọc trực tiếp trạng thái và lịch sử phát hiện thật từ Windows Defender - antivirus engine mặc định của Windows với cơ sở dữ liệu chữ ký được Microsoft cập nhật liên tục. Đây là phương pháp đáng tin cậy nhất để liệt kê file (.exe, .doc, ...) đã bị phát hiện nhiễm mã độc, thay vì tự dò quét bằng heuristic tự viết (vốn kém chính xác và dễ gây hiểu lầm).
